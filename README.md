# NVDA Overnight Momentum

Demo website for the **NVDA Overnight Momentum** Playbook, built for Bitget AI Hackathon S2.

## Features
- Clear parameter display
- One-click copy of Playbook prompt
- One-click copy of parameters as JSON
- Instructions for $10k paper simulation on GetAgent Studio
- No live trade execution on the site

## Local Run
```bash
npm install
npm run dev
```

## Deploy
Deploy the `public` folder to Vercel or Netlify.
